RAHILA'S 22ND BIRTHDAY WEBSITE

START THE WEBSITE
1. Extract this ZIP.
2. In VS Code choose File > Open Folder and select rahila_birthday_separate_pages.
3. Install the VS Code extension Live Server if needed.
4. Right-click welcome.html > Open with Live Server.
5. Password: githi

COUNTDOWN AND FOLDER STRUCTURE
rahila_birthday_separate_pages/
  welcome.html, index.html, memories.html, photos.html, videos.html, ...
  css/style.css
  js/script.js
  photos/       <- put your pictures here
  videos/       <- put your videos here


IMPORTANT
Open the extracted project folder in VS Code and run welcome.html using Live Server. Do not double-click the HTML file (file://).
